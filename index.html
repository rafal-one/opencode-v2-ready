Is your OpenCode plugin ready for V2?

OpenCode 2.0 has a new plugin API and V1 plugin implementations do not run in V2 (official migration guide). Of 2561 npm packages tagged opencode-plugin: 514 are on the V2 API, 165 support both, 1702 are V1 only, 180 are unclear. Updated 2026-10-19 (@opencode-ai/plugin 1.19.3, @opencode/plugin 2.0.32).

Check your opencode.json

Paste it (nothing is uploaded; only plugin names go to the npm registry), or run pip install opencode-v2-ready && opencode-v2-ready check in your project.
