Port an OpenCode plugin from V1 to V2

The official guide: Migrate V1 plugins. There is no automatic conversion. Summary of the mechanical steps:

  1. Depend on @opencode/plugin instead of @opencode-ai/plugin.
  2. Replace the exported function with export default Plugin.define({ id: "my.plugin", async setup(ctx) { ... } }); the id is required.
  3. Read directory/project from ctx.location, options from ctx.options, and use domain methods instead of client.
  4. Register hooks inside setup (table below); the callback gets one mutable event.
  5. In opencode.json rename plugin to plugins; ["pkg", {opts}] becomes { "package": "pkg", "options": {opts} }.
